# Changelog

## 0.1.0-alpha.1 — 2026-10-16

Initial source alpha. Includes the shadcn-derived chat UI, Pi Durable conversations, Chrome tab tools, optional background noVNC desktop control, authenticated pairing and revocation, portable configuration, isolated browser smoke/live demos, and public setup/interface documentation.

This is a single-owner experiment with source installation only. No npm package, installer, Chrome Web Store listing, multi-user service, or stability guarantee is provided. See the [verification record](docs/verification.md) for tested combinations and limitations.
